# stock-alert-console

A-share monitoring console — portable asset repo.

Contents:
- `stock-alert-console/` — the console (`console.html` is the only deliverable)
- `_tests/` — full regression tests and backtest scripts
- `股票监控系统-需求与方案说明.md` — requirements & design doc (includes the cross-machine / handoff checklist in section 8)

Clone this repo, then open the requirements doc in WorkBuddy to continue development on a new machine.
