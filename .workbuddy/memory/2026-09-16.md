### 功能价值评估（写入文档 2.4 节，编号 V1–V6）

判断出的**核心断层**：系统只是"价格穿越提醒器 + 情绪查看页"，只答"价格到了吗/现在多少度"，
不答"我该做什么"。三个原因：① 只认价格不认持仓 → 算不出盈亏、说不出"卖多少"；
② 恐贪已给出很具体的建议，但**建议与动作之间没有执行工具**（最大浪费）；
③ 真正该被叫醒的时刻（情绪极值、浮亏扩大、盈利回吐）系统不知道。

**结论：不是加指标，而是从"提醒器"变成"持仓决策闭环"。**

- 第一梯队（小改动、直接减少实际损失）：**V1 情绪极值主动推送**（恐贪<20/>80 主动推 + 阶段 + 该做什么）、**V2 任务心跳+失败告警**（现状是单点，Actions/Server酱 静默失败你不会知道）。
- 第二梯队（有依赖顺序）：**V3 持仓账本**（地基，没它 V4/V5 都做不了）→ **V4 按盈亏提醒 + 移动止盈**（把价格翻译成"我的钱"）→ **V5 分批计划执行器**（情绪到冰点自动进入分批节奏，只有本系统能做的组合拳）。
- 第三梯队：**V6 提醒历史 + 触发后 5/20/60 日收益追踪**（算出自己规则的胜率，可复盘）。
- 明确不做：分时/K线图、批量导入、多用户、再加技术指标、个股 AI 点评、开盘收盘定时播报（与心跳重复且非事件驱动）。
- 建议顺序 **V1 → V2 → V3 → V4 → V5 → V6**。
