## A股前复权价格监控小程序（可交付项目）

**产出目录**：`D:\mywork\stock-monitor`

**需求**：微信小程序，按名称/代码添加 A 股，支持开启/暂停/删除监控；价格等于/大于/小于目标价时推送微信通知；使用者是编程小白，需要完整部署指引。

**技术方案（最终选定）**
- 前端：原生小程序（4 个页面：index 列表 / add 搜索 / detail 详情+K线 / help 说明）
- 后端：微信云开发
  - `stockApi` 云函数 —— 行情代理（搜索、实时行情、前复权K线、登录+自动建表）
  - `monitor` 云函数 —— 定时触发器（cron `0 */5 9-15 * * * *`），交易时段判断 → 批量比价 → 云调用 `subscribeMessage.send`
- 数据库：`stocks` / `user_sub` / `notify_log`，权限均为「仅创建者可读写」

**关键设计决策**
- 行情源用**东财 push2 系列**（UTF-8 JSON，避开腾讯/新浪的 GBK 解码坑），K线用**腾讯 fqkline `qfq`**（前复权），并保留东财 `fqt=1` 作为备用源。
- 触发语义定为**边沿触发**：只在「不满足 → 满足」那一刻提醒一次，价格回到条件外自动复位，避免震荡刷屏。
- 微信公众号订阅消息是**一次性订阅**（授权1次=发1条），因此在 `user_sub` 里自建额度计数，前端提供「补充订阅」按钮攒额度。个人主体无法申请长期订阅。
- 模板字段（thing1/amount2/...）因模板而异，抽成 `cloudfunctions/monitor/config.js` 的 `FIELDS` 映射，让用户自己填。

**踩过的坑（重要）**
1. 东财 `ulist.np/get` 加 `fltt=2` 时返回的是**真实小数**（1278.5），不应再按 f1 小数位缩放；不加 fltt 才返回放大整数（127850）。最初写了两处都缩放，导致价格变成 12.785。
2. 东财 `push2.eastmoney.com` 在部分网络下会 `socket hang up`，需多域名容灾（`push2delay` / `push2` / `82.push2` / `push2his`）。实测 `push2delay` 最稳。
3. 腾讯 `qt.gtimg.cn` 和 新浪 `hq.sinajs.cn` 返回 GBK，中文名可能包含 `0x7E`（即 `~`）导致按 `~` 分割错位，所以只把它们当备用，主力用 UTF-8 的东财。
4. 云函数 `config.json` 必须声明 `permissions.openapi: ["subscribeMessage.send"]` 才能云调用发订阅消息。
5. `miniprogramState` 填错（developer/trial/formal）会导致通知**静默失败**，调试期必须填 `developer`。

**验证方式**
自建 `wx-server-sdk` 替身 + 测试脚本，真实调用行情接口跑通全链路，43 项断言全绿；项目 36 项结构与语法校验通过。临时测试目录已清理。
