### 根因（好消息：一个真正的 bug 而非"没做"）

持仓页看不到实时价是**两个缺陷叠加**：

1. **取价范围缺持仓清单**：`refreshPrice` 的 need 只拼 `cfg.stocks`（监控清单）+ 归档里触发过的，
   **不含 `cfg.holdings`** → 「只持有、未监控」的股票永远拿不到行情价（浮盈算不出、全显示"暂未取到行情价"）。
2. **行情回来后不重渲持仓页**：`openHoldings()` 是先 `renderHoldings(G.quoteMap)` 再 `refreshPrice(true)`，
   行情回来时只重渲 renderActive/renderArchive/renderDash → **持仓页停在首帧**（首次打开 map 还是 null → 永远"行情加载中"）。

推荐页同理：推荐存档是**打开页面时**才从云端读的，此前那次取价里没有这些代码。

### 关键算法坑（都已在代码里注释）

1. **主力净额 = −散户净额**（同一笔交易两面）→ 只看资金流分不出"割肉"和"追高"，**必须叠价格方向**当第三维。
   散户「割肉」= 价跌 + 散户净卖出；「追高接筹码」= 价涨 + 散户净买入；「抄底」= 明显下跌 + 散户净买入。
2. **锁仓判定不能只判缩量**（否则"缩量但主力猛买"误判锁仓）→ 必须加 `flowDir(dom20)==='flat'`。
3. **阈值**：`strongDom=0.04, midDom=0.012`（1.2% 的主力量能若当"无方向"，会出现
   "散户净买 + 主力无方向"的自相矛盾）。
4. **`m.mainBehavior = judgeMain(m)` 必须在 `judgeStance(m)` 之前回写**（否则 `Cannot read properties of undefined 'key'`）。
5. 集中度口径曾错（90% 带宽/均价），改为**现价 ±10% 内筹码占比**。

### 5 日线连续站上（用户指定口径）

- 实现在已注入的 `SignalCore.ma5Streak(bars, endIdx)`：**开盘与收盘都高于「截止当日」的 5 日线**才算站上，
  逐日各用当天的 5 日线，从最新往前数连续天数。返回 `{days, sig, ma5, from, to}`。

## ★ 第六轮：首页刷新变白板（用户反馈「首页页面数据刷新的时候，页面会变成白板，加载。体验不好」）

### 根因（读代码确认，两条叠加）

1. **`#dash` 静态就是个空 div**（`<div id="dash"></div>`），而 `boot()` 要
   `await loadConfig()` → `await loadState()` **两轮 GitHub API** 之后才第一次 `renderDash()`。
   在手机上（微信 webview + 境外 API）这段时间就是**一片背景色 + 「正在加载…」= 白板**。
2. **行情每次回来都整块 `innerHTML` 重画**：`refreshPrice` 里 `renderActive/renderArchive/renderDash`
   无差别重建 DOM —— 即使数据一个字节没变。结果是页面闪一下、滚动位置和用户刚展开的面板被打回去。

### 修复（三条）

| # | 做法 | 关键点 |
|---|---|---|
| ① | **首屏骨架** | `#dash` 里直接内嵌三张卡骨架（`.sk` 灰条 + 复用现有 `skpulse` 脉动动画）。第一次进来也有"形"，不是白板 |
| ② | **本地缓存秒开** | 新增 `CACHE_KEY='sa_cache_v1'` + `readCache/writeCache/clearCache` + `paintFromCache()`。`boot()` 一进来（**同步、不联网**）先用上次的 `cfg/state/quotes` 把首页铺满，再去 `loadConfig()`；行情/保存成功后 `writeCache()`。**因此顺序不能反**（有测试钉死） |
| ③ | **有变化才重画** | 新增 `paint(el, html, key)`：内容签名一致就**一个字节都不动 DOM**、返回 false。`renderDash/renderActive/renderHoldings/renderPicks` 四处都改用它（`dashSig/actSig/holdSig/pickSig`） |

配套：
- 刷新失败时**保留缓存数据**（顶部提示「刷新失败：…下面是上次的数据」），不再把用户一脚踢去设置页
- 顶部同步条文案改成「X 分钟前更新 · 正在后台更新…」，说清是"在更新"而不是"卡住了"
- **换仓库 / 恢复备份 → `clearCache()`**（否则首屏会拿另一个仓库的数据顶上来）
